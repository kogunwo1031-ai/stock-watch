# 저평가 워치 (개인용)

국내·미국 약 6,800종목(코스피·코스닥, S&P 500·나스닥 100·러셀 2000 등)과 저평가 우량주 리서치를 폰에 설치해 쓰는 앱입니다. 일봉 차트(이동평균·볼린저·RSI·MACD), 실시간 BEST·시장 지도·테마, 골라보기, 관심종목·매수 희망가·보유·메모(폰에 저장)를 담았습니다.

## 설치 (안드로이드)
1. 폰에서 이 저장소의 **Releases** → 최신 `StockWatch.apk`를 누릅니다.
2. '출처를 알 수 없는 앱 설치'를 한 번 허용하고 설치합니다.

APK 없이 쓰려면: 폰 Chrome으로 웹 앱 주소(`https://<계정>.github.io/<저장소>/`)를 열고 메뉴 ⋮ → **앱 설치**(또는 홈 화면에 추가).

## 갱신
- 평일(화~토) 아침 Claude 예약 작업이 전날 종가·일봉을 새로 받아 `site/`를 올립니다. 앱은 다음에 열 때 자동으로 새 데이터를 보여 줍니다(재설치 불필요).
- 인터넷이 없으면 마지막으로 받은 데이터를 보여 줍니다.

## 구조
- `site/` 웹 앱(PWA). `tools/build_app.py`가 만듭니다.
- `tools/` 데이터 파이프라인: `build.py`(엑셀·data.json), `history_tool.py`(일봉 저장소), `research.json`(리서치 원본).
- `android/` 웹 앱을 여는 안드로이드 앱 껍데기. `.github/workflows/android.yml`이 APK를 빌드합니다.

## 백업
관심종목·메모는 폰에만 저장됩니다. 앱을 지우기 전 오른쪽 위 ⋯ → **내 기록 백업 · 복원**에서 복사해 두세요.

공개 자료를 정리한 참고용 도구이며 투자 권유나 금융 자문이 아닙니다.
